# 💬 Chatbot Web Application

## 📖 Overview

This project is a lightweight, browser-based **Chatbot Web Application** designed to simulate a customer support interface. It provides users with quick, predefined responses for common service-related queries through an intuitive chat UI.

The application demonstrates core front-end development concepts such as DOM manipulation, event handling, and conditional logic implementation.

---

## 🚀 Key Features

* Interactive real-time chat interface
* Predefined conversational logic for customer support queries
* Quick reply buttons for improved user experience
* Keyboard (Enter key) and button-based input handling
* Clean and responsive user interface

---

## 🛠️ Technology Stack

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
* **UI Styling:** Custom CSS, Google Fonts
* **Icons:** Font Awesome
